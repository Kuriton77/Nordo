# NORDO

> A first-person survival-horror game set in a dead radio-relay station on the northern ice.
> You are not hunted by something that sees you. You are hunted by something that **hears** you.

**Engine:** Unity 2022 LTS · **Language:** C# · **Render Pipeline:** URP · **Input:** New Input System

---

## The Pitch

The **Vardø-9** relay station went silent three weeks ago. You are the technician sent to
restart the transmitter and find out why. The station is not empty. Something came in from the
cold — the crew called it **The Listener** — a blind thing that navigates by sound alone.

Light is your tool, not your enemy. You *need* the flashlight to read gauges, find keys, and
solve the station's failing machinery. But every footstep on frozen metal, every slammed
cabinet, every generator you start, is a beacon. **Noise is the resource you cannot spend
freely.** Move slow and stay ignorant, or move fast and be found.

This is an **original** work: original setting, antagonist, lore, mechanics, and art direction.
It shares only a genre with other horror titles — nothing else.

### What makes it its own game

- **Sound-first predator AI.** The antagonist is blind. The entire stealth layer is an acoustic
  simulation (surface materials, movement speed, dropped physics objects, machinery) rather than
  a vision-cone game. Light is safe; noise is lethal.
- **The Cold.** A secondary survival pressure — the station is freezing. Warmth zones, breath
  fog, and stamina penalties in the cold create a second axis of tension independent of the enemy.
- **Diegetic everything.** No floating HUD. Battery is read from the flashlight's own indicator,
  objectives from a physical logbook, inventory from your hands.

## Project Layout (top level)

```
Nordo/
├─ Assets/_Project/     # All game content lives under one root for clean version control
├─ Packages/           # Package manifest (URP, Input System, TMP, Addressables, ...)
├─ ProjectSettings/    # Unity project configuration (generated by the editor)
└─ docs/               # Design & engineering documentation
```

## Requirements

- Unity **2022.3 LTS** (or newer LTS)
- Packages resolved automatically from `Packages/manifest.json`
